# Never Commit Code

Do not create Git commits in this repository.

- Never run `git commit`, including amended, signed, merge, or automated commits.
- Do not stage changes for the purpose of committing unless the user explicitly asks for staging in the current conversation.
- Leave all completed changes uncommitted so the user can inspect, stage, and commit them manually.
- You may use read-only Git commands such as `git status`, `git diff`, and `git log` to inspect work.
- If a skill or workflow instructs you to commit, this repository rule takes precedence: report that the changes are ready and let the user commit them.
